# Diseño físico

Esta carpeta contiene los archivos relacionados con el diseño físico del
proyecto, incluyendo el modelo 3D, el esquema electrónico y el diseño de
la PCB.

Los archivos fueron desarrollados como parte del trabajo académico en
equipo. El diseño de la PCB y el modelo 3D corresponden a propuestas de
diseño; no se fabricó físicamente la PCB ni se imprimió el modelo 3D.
