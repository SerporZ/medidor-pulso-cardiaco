# Simulación del circuito

Esta carpeta contiene los archivos relacionados con la simulación del
circuito del medidor de pulso cardiaco realizada en Multisim.

## Propósito

La simulación se utilizó para analizar el comportamiento del circuito,
revisar las conexiones y apoyar la etapa de verificación antes del montaje
físico en protoboard.

## Archivo principal

- `PROYECTO FINAL SIMULACION`: archivo de simulación desarrollado en
  Multisim.

El nombre y la extensión exacta pueden variar según la versión del programa
utilizada.
